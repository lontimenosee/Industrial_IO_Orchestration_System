# GUI 测试引导

本文用于测试工业 I/O 接口智能编排系统的第一版 Flet 界面。当前可用页面为“工程概览”和“任务编排”；CAD 解析、规则编排、Excel 写入、人工确认、容量报告和差异报告仍是接口预留，不应将它们视作已实现功能。

## 1. 测试前准备

在 PowerShell 中进入项目目录：

```powershell
Set-Location D:\Industrial_IO_Orchestration_System
```

确认项目虚拟环境可用：

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -c "import flet; print(flet.__version__)"
```

预期：Python 为 3.12，且能输出 Flet 版本号。

如测试命令提示缺少 pytest，仅在本项目虚拟环境中安装：

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
```

## 2. 启动应用

```powershell
.\.venv\Scripts\python.exe .\src\main_gui.py
```

预期：出现标题为“工业 I/O 接口智能编排系统”的桌面窗口，左侧为深蓝色导航栏，默认展示“工程概览”。关闭窗口即可结束程序。

## 3. 手工功能测试

### 用例 1：工程概览默认状态

1. 启动应用。
2. 保持未选择任何文件。

预期：

- 页面显示“工程概览”。
- 指标卡包含“当前任务状态”“待确认”“容量风险”“业务接口”。
- 当前任务状态为“等待配置”。
- 最近任务日志提示需要选择 CAD/DXF 图纸和 Excel I/O 点表。

### 用例 2：页面导航

1. 点击左侧“任务编排”。
2. 点击左侧“工程概览”。
3. 点击概览页的“创建编排任务”。

预期：

- 前两次操作在“工程概览”和“任务编排”之间切换。
- “创建编排任务”跳转到“任务编排”。
- 侧边栏当前页面按钮有高亮样式。

### 用例 3：缺少必填文件时的预检

1. 进入“任务编排”。
2. 不选择文件，点击“开始预检”。

预期：

- 出现红色提示，内容同时包含“CAD/DXF 图纸”和“Excel I/O 点表”。
- 返回概览页后，“当前任务状态”显示“等待补充输入”。
- 日志记录本次缺项提示。

### 用例 4：选择文件与预检通过

1. 点击“CAD/DXF 图纸”右侧的“选择文件”，选择任意 `.dwg` 或 `.dxf` 文件。
2. 点击“Excel I/O 点表”右侧的“选择文件”，选择任意 `.xlsx`、`.xlsm` 或 `.xls` 文件。
3. 可选：为规则配置选择 `.json`、`.yaml` 或 `.yml` 文件。
4. 点击“开始预检”。

预期：

- 已选文件的文件名显示在对应区域。
- 出现“预检通过：业务接口预留，尚未读取工程文件。”提示。
- 概览页任务状态变为“预检通过（接口待接入）”。
- 测试期间应用不解析 CAD 内容，也不读取或修改 Excel 内容。

### 用例 5：执行编排的安全边界

1. 在“任务编排”页面点击“执行编排”。

预期：

- 出现“接口预留，等待业务脚本接入后执行编排。”提示。
- 不创建新 Excel、报告或其他工程输出文件。
- 原始 CAD/Excel 文件时间戳和内容不发生变化。

### 用例 6：后续功能入口

1. 依次点击“人工确认”“容量报告”“差异报告”。

预期：每次显示“将在后续版本开发，目前保留导航入口”的提示，不跳转到未实现页面，也不发生异常。

## 4. 自动化测试

运行 GUI 状态和视图构造测试：

```powershell
.\.venv\Scripts\python.exe -m pytest test -v
```

预期：5 项测试通过，覆盖：

- CAD/Excel 必填项预检；
- 已选择路径时的预检；
- 未接入业务脚本时的明确反馈；
- 工程概览关键文本；
- 任务编排关键输入和操作入口。

额外执行语法检查：

```powershell
.\.venv\Scripts\python.exe -m py_compile .\src\main_gui.py
```

预期：命令无输出且退出码为 0。

## 6. 当前版本限制

- 文件选择仅保存路径和显示文件名。
- 预检只判断是否选中 CAD/DXF 与 Excel 路径。
- “待确认”“容量风险”等概览数字为界面样例。
- 应用不会读取、改写、复制或导出工程文件。
- 后续接入应通过 `BackendAdapter` 对接 CAD 解析、规则引擎、通道分配、Excel 导出和报告模块。
