# 工业接口智能编排系统
## 项目简介

工业接口智能编排系统面向工业自动化工程设计场景，
目标是利用图纸语义解析、规则约束和自动化编排技术，
辅助完成从设备测点识别到 I/O 接口分配的工程流程。

本项目主要负责系统中的业务规则与输出层，
承接上游语义解析模块输出的结构化测点信息，
结合工业业务规则、设备模板和已有 I/O 资源情况，
完成测点标准化、接口资源分配以及工程文件输出。

---

## 负责功能范围

本模块主要实现以下功能：

### 1. 测点规则解析

根据工业仪表信息和业务规则，
对输入测点进行标准化处理。

主要包括：

- 信号类型识别
    - AI
    - AO
    - DI
    - DO
    - TC
    - RTD

- 就地仪表过滤

- 不确定测点标记

- 人工确认信息记录


### 2. 设备模板展开

针对工业现场常见设备，
根据设备类型自动补充相关 I/O 点。

例如：

- 电机
- 油泵
- 风机
- 电加热器

同时完成：

- 自动展开附属测点
- 重复测点检测
- 疑似重复提示


### 3. I/O 通道增量分配

根据已有工程 I/O 点表资源，
建立通道资源池。

实现：

- 卡件通道管理
- 通道状态识别
- 20%冗余约束
- 新增测点自动分配

保证：

- 不覆盖已有点位
- 不占用预留资源
- 输出无法分配原因


### 4. Excel 工程点表生成

基于原始工程 Excel 文件，
进行增量式修改。

实现：

- 新增 I/O 点写入
- 保留原文件格式
- 输出新的工程点表


### 5. 差异报告输出

生成工程人员可查看的结果报告：

包括：

- 成功分配点列表
- 未分配点列表
- 疑似重复点列表
- 通道容量统计
